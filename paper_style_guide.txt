%--- 7c. Diagnostics Menu ---
%
% Every regression table MUST include a diagnostics panel separated
% from coefficients by \midrule. Include ALL items that apply to the
% estimator used. Use --- for items that do not apply to a given column.
%
% ALWAYS report:
%   - N (observations)
%   - $R^2$
%   - Adjusted $R^2$
%   - Dep.\ var.\ mean (helps interpret coefficient magnitude)
%   - SE type stated in notes (robust, clustered, HC1, bootstrap, etc.)
%
% Report when applicable:
%   - Within $R^2$              — panel FE models
%   - Fixed effects             — list which (unit, time, unit$\times$time, etc.)
%   - Clusters                  — level and count, e.g., "1{,}938 blocks"
%   - First-stage F             — IV / 2SLS
%   - Instrument(s)             — IV / 2SLS (name or brief description)
%   - Kleibergen-Paap rk Wald F — IV with clustered SEs
%   - Anderson-Rubin p-value    — IV with weak instrument concerns
%   - Bandwidth                 — RD / local polynomial
%   - Kernel                    — RD / local polynomial
%   - Polynomial order          — RD / parametric
%   - Eff.\ N (left / right)   — RD (observations within bandwidth)
%   - Placebo cutoff p-value    — RD falsification
%   - Pre-trend test p-value    — DiD / event study
%   - Estimator                 — when non-obvious (CS, SA, GSC, etc.)
%   - Weights                   — if applicable (population, IPW, etc.)
%   - Controls                  — Yes / No, or list key controls
%   - Sample restriction        — if columns differ by subsample

%  8. EQUATIONS
%==========================================================
% - Numbered equations use the equation environment
% - Follow equations with \noindent where: and a bullet-less itemize
%   for variable definitions:
%
%   \begin{equation}
%       Y_{it} = \alpha_i + \gamma_t + \beta X_{it} + \varepsilon_{it}
%   \end{equation}
%   \noindent where:
%   \begin{itemize}
%       \item[] $Y_{it}$ = outcome for unit $i$ in period $t$
%       \item[] $\alpha_i$, $\gamma_t$ = unit and time fixed effects
%       \item[] $X_{it}$ = treatment variable
%   \end{itemize}
%
% - Use \text{} for words inside math mode: $\Delta\ln\text{Value}_i$
% - Use \widehat{} for fitted/predicted values
% - Label multi-stage models with \textbf{First stage:}, \textbf{Second stage:}

%==========================================================
%  9. TEXT CONVENTIONS
%==========================================================
% Abbreviations & spacing:
%   - Backslash-space after mid-sentence abbreviation periods:
%       U.S.\ Census, e.g.\ this example, i.e.\ that is
%   - This prevents LaTeX from treating the period as end-of-sentence
%
% Punctuation & typography:
%   - En-dash for ranges: 2015--2020, 8--9 AM, pp.\ 12--34
%   - Em-dash for interjections: ---no space on either side
%   - Curly quotes: `` '' (backticks for open, apostrophes for close)
%   - Percent: 40\%
%   - Dollar amounts: \$100{,}000
%
% Cross-references:
%   - Non-breaking space before refs: Figure~\ref{fig:...}, Table~\ref{tab:...}
%   - Always capitalize: "Figure 1", "Table 2", "Equation 3"
%
% Citations (author-year, inline):
%   - Running text: Author (Year) — e.g., Hansen (1959)
%   - Parenthetical: (Author Year) — e.g., (Karner et al.\ 2022)
%   - Multiple: semicolon-separated — (Author1 Year; Author2 Year)
%   - Three+ authors: use "et al." after first author

%==========================================================
%  12. WRITING CONVENTIONS
%==========================================================
% Voice & person:
%   - First-person plural: "We estimate...", "Our results show..."
%
% Numbers:
%   - Spell out one through nine in prose
%   - Use digits for 10+, all units, and all tables/figures
%
% Terminology:
%   - Define acronyms on first use: "Average Annual Daily Traffic (AADT)"
%   - Capitalize proper nouns and named frameworks: "Ricardian", "Granger"
%   - Keep technical terms lowercase in running text unless a proper noun
%
% Structure:
%   - One idea per paragraph
%   - Use \footnote{} sparingly — for supplementary details or URLs only
%   - Bulleted lists (\begin{itemize}) for parallel points;
%     numbered lists (\begin{enumerate}) for sequential/ordered claims
