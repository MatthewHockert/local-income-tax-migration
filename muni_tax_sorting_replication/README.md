# Replication Package

**Paper:** *Do Local Taxes Cause Residential Sorting?* (`manuscript/muni_tax_sorting.tex`)
**Author:** Matthew Hockert — matthew.hockert@gmail.com

> **Status note.** This manuscript is a **working draft under active revision**. The package
> faithfully reproduces every table, figure, and in-text number in the current `.tex`. The
> empirical design is the EIT continuous stacked difference-in-differences at the municipality
> level; the property tax appears as institutional background and as a competing-burden control,
> not as a co-equal treatment. (An earlier two-tax-comparison version is preserved in the
> project's git history; its property-tax estimation scripts are kept in the source repository
> but are **not part of this paper** and are therefore not included here.)

This package reproduces the paper from the included inputs. Install the listed software, then
run the scripts in `scripts/` in the order in §3; outputs are written to `tables/` and
`figures/`, and the manuscript in `manuscript/` compiles against them.

## 1. Software requirements
- **R** ≥ 4.2 (verified on 4.x). Install packages:
  ```r
  install.packages(c("data.table","fixest","dplyr","tidyr","stringr","sf",
                     "ggplot2","readxl","janitor","tigris","lehdr",
                     "tidycensus","stringdist","beepr",
                     "openxlsx","HonestDiD"))   # openxlsx: results workbook; HonestDiD: pre-trend battery
  ```
- **Python** ≥ 3.9 — only for the one-time raw scrapers in §3 step 1:
  ```bash
  pip install requests pandas xlrd
  ```
- **LaTeX** distribution with `biber` (TeX Live 2021+) to recompile the manuscript.
- **Run time / hardware:** the estimation→tables→figures path (§3 steps 3–5) runs in
  ~3–5 min on a modern laptop (8 GB RAM). Rebuilding the panels from raw LODES (step 2) needs
  the ~1.5 GB LODES download and ~60 min; **the assembled panels are vendored so this step is
  optional.**

## 2. Folder structure
```
muni_tax_sorting_replication/
├── README.md
├── scripts/      <- config.R + paper_helpers.R + the canonical pipeline
├── data/         <- vendored panels + result CSVs (large/raw documented, §4)
│   └── q3_unified/   <- estimation result CSVs (regenerated by step 3)
├── tables/       <- OUTPUT: regenerated LaTeX table fragments
├── figures/      <- OUTPUT: regenerated PNG figures
└── manuscript/   <- muni_tax_sorting.tex, .bib, compiled PDF
```
Every script sources `scripts/config.R` first, which resolves the package root from its own
location — so the package runs wherever it is unzipped, with no path edits.

## 3. How to reproduce
From the package root. **Steps 1–2 are optional** (their outputs are vendored); start at step 3
to reproduce all exhibits from the vendored panels.

```bash
# 1. Raw acquisition — ONE-TIME, needs internet; outputs are vendored already.
python3 scripts/scrape_pa_dced_eit.py      # DCED EIT/property tax register
Rscript  scripts/reparse_dced.R            # recover SD id on DCED rates
python3 scripts/scrape_pa_dced_afr.py      # DCED muni AFR (fiscal controls)
python3 scripts/scrape_nces_sd_finance.py  # Census F-33 SD finance
Rscript  scripts/download_lodes.R          # PA block LODES (~1.5 GB, ~60 min)

# 2. Build panels from raw (needs LODES from step 1). Outputs vendored.
Rscript scripts/build_data.R               # cousub panels + block->cousub xwalk
Rscript scripts/build_block_panel.R        # block x year panel
Rscript scripts/build_sd_controls.R        # F-33 -> SD share controls + xwalk

# 3. Estimation — re-runs from VENDORED panels (no LODES needed). ~2 min.
Rscript scripts/q3_unified_full_table.R    # headline binding decomposition  [VALIDATION GATE]
Rscript scripts/q3_unified_headline_es.R   # realized-dose pre-trend ES
Rscript scripts/q3_unified_pooled.R        # pooled-Increase benchmark
Rscript scripts/q3_unified_pooled_es.R     # pooled ES
Rscript scripts/q3_unified_act32_3level.R  # pre/post Act 32 split
Rscript scripts/q3_unified_act47_robustness.R  # Act 47 exclusion
Rscript scripts/q3_unified_eit_revenue.R   # EIT revenue response (in-text numbers)

# 4. Tables + figures -> tables/ and figures/. ~1 min.
Rscript scripts/build_summary_stats.R          # summary tables + map + rate/coverage figs
Rscript scripts/build_paper_tables.R           # headline / pooled / act32 / es / app tables
Rscript scripts/build_appendix_es_figures.R    # es_realized_* figures
Rscript scripts/build_uea_aggregate_figures.R  # pooled_es + dose-trajectory (muni vs SD)
Rscript scripts/build_dose_trajectory_inc_becomes.R

# 5. Compile the manuscript.
cd manuscript && pdflatex muni_tax_sorting && biber muni_tax_sorting && \
  pdflatex muni_tax_sorting && pdflatex muni_tax_sorting
```

A successful step 3 prints the **validation gate** in `q3_unified_full_table.R`:
```
[validation] headline Inc-bind matches paper:  log_LW=-0.573 log_IC=-0.412 log_TJ=-0.490 share=-0.058
```
(The script `stop()`s if any headline Inc-bind coefficient drifts more than 0.005 from these.)

## 4. Data
All inputs are in `data/`. Provenance and reproducibility status:

| `pa_eit_rate_panel.csv` | Muni + SD EIT resident/nonresident rates, 2002–2019 | PA DCED Municipal Statistics tax register (public) | Yes — `scrape_pa_dced_eit.py` + `reparse_dced.R` |

| `pa_sd_controls.rds`, `pa_sd_id_xwalk.rds` | F-33 share controls + NCES↔DCED SD crosswalk | Derived from F-33 + DCED | Yes — `build_sd_controls.R` (see manual note) |
| `pa_panel.rds`, `pa_rate_panel.rds`, `pa_residence_panel.rds` | Cousub × year workplace/residence/rate panels | Derived from LODES + DCED | Yes — `build_data.R` (needs LODES) |
| `pa_block_panel.rds`, `pa_block_xwalk.rds` | Block × year panel + block→cousub crosswalk | Derived from LODES + TIGER 2020 | Yes — `build_block_panel.R`, `build_data.R` |
| `pa_cousub.rds` | PA cousub geometry (for `pa_map`) | Census TIGER 2020 via `tigris` | Yes |
| `data/q3_unified/*.csv` | Estimation result CSVs backing the tables | Derived | Yes — step 3 regenerates them |
| `data/lodes_block/` *(not in git)* | PA block-level LEHD/LODES OD, 2002–2019 (~1.5 GB) | LEHD LODES v8 (public) | Yes — `download_lodes.R`; large, see below |

**Manual-classification note.** The pipeline is rule-based, with **two** human inputs to flag:
(1) the **NCES↔DCED school-district crosswalk** (`build_sd_controls.R`) is automated name
normalization + Jaro–Winkler fuzzy matching, but includes **2 hand-coded overrides** for
completely-renamed districts (KNOCH ↔ SOUTH BUTLER CO; RIVER VALLEY ↔ BLAIRSVILLE SALTSBURG);
500/500 districts match. (2) The DCED-municipality → Census-cousub match is name+county based
(~99.6% automatic). The binding-cell classification (Inc-bind / Inc-becomes / Inc-nobind) is a
deterministic transform of the rate panel, **not** a judgment call.

**Large / restricted data.** Nothing is restricted. The only heavy input is **LODES**
(`data/lodes_block/`, ~1.5 GB) and the DCED raw register (`data/pa_dced_raw/`, ~187 MB), both
git-ignored. They are regenerated by step 1, or obtained from the data deposit. The vendored
panels make steps 3–5 runnable without them. For the archival deposit (Zenodo/openICPSR),
include the git-ignored files listed in `.gitignore` alongside the tracked package.

## 6. Notes
- **Sample:** 2002–2019 (LODES 2020–21 and ARPA-distorted fiscal years excluded).
- **One source of truth:** all numbers come from the scripts above; `tables/` and `figures/` are
  regenerated outputs, not hand-edited.
- **Bibliography:** `local_income_taxes_2.bib` is auto-exported from the reference manager;
  `local_income_taxes.bib` is the prior manual copy. Edit citations in the manager, not the file.
- **`build_paper_tables.R`** still reads several non-paper result CSVs (block/SD/industry) it
  inherited from the larger project; the vendored `data/q3_unified/` includes them so it runs
  unmodified. Only the cousub/EIT fragments listed in §5 feed this paper.
